# 06: Diagrams — the retrieval service

**What to build:** Three real architecture diagrams replacing the placeholder slots on this project's card, drawn as components that render inline vector graphics rather than images (ADR-0004).

They must be technically accurate to the system as the source material describes it. Generated or approximated diagrams get detail subtly wrong — invented components, arrows the wrong way round — and this is the one audience that reads a pipeline closely. A wrong arrow undermines the exact claim the site is making.
